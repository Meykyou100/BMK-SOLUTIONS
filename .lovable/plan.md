# BMK SOLUTIONS website

## Goal
Create a complete French-language showcase website for BMK SOLUTIONS, using the supplied logo unchanged as the official brand asset.

## Scope
- Build a polished, mobile-friendly single-page site with clear navigation to services, company information, reasons to choose BMK, a quote form, and contact details from the supplied brief.
- Preserve the logo artwork, colors, and proportions in the header/footer; create a padded square favicon from the same logo.
- Use a cohesive set of realistic service photos, restrained motion, and accessible navigation and form controls.
- Validate required quote details and open a prefilled WhatsApp message addressed to the supplied number; provide working phone and direct WhatsApp links.
- Add BMK-specific page metadata and verify the quote flow, responsive layout, and build status.

## Technical details
- Keep the site on the existing TanStack Start home page, with section anchors for the one-page showcase.
- Use the existing design system, semantic tokens, and available UI dependencies; no backend is needed because quote requests are handed off to WhatsApp.
- Do not invent certifications, metrics, partners, or an unverified map location.
